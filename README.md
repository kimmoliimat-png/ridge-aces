# Ridge Aces

Side-view WWI-inspired bombing raids. Fly a triplane along a ridge, bomb enemy bases, land on green strips to refuel, and push a rival squadron off the map.

Original arcade game. Not affiliated with Triplane Turmoil.

## Play

Portrait or landscape, keyboard or touch.

- **Start** — one-post Dawn Raid
- **Campaign** — five raids vs one rival, getting longer and meaner
- **Skirmish** — two posts, free hunt

### Controls

| Input | Action |
| --- | --- |
| Hold left pad / W | Climb |
| Drag down / S | Dive |
| A / D | Turn |
| Gun button / Space | Fire |
| Bomb button / X | Drop bomb (carries plane speed; stall dumps straight down) |
| Idle on a green **STRIP** | Repair and refuel |

Fuel empty = engine dies. You still glide. HUD points you at the nearest strip.

## Campaign

1. First Blood — one lookout
2. Cut the Dumps — two posts
3. The Battery — three posts, fuel runs thin
4. Their Hunt — bomber inbound, three posts
5. Ace of the Ridge — four last yards, their ace in the air

Hardest maps sit past a tank of fuel. Land and sit still at least once.

## Stack

Web app (TanStack Start + Vite + Canvas 2D). Offline-friendly PWA. No accounts, no ads. Progress is local.

```bash
npm install
npm run dev
```

Open the local URL the dev script prints. Production:

```bash
npm run build
npm run preview
```

Play Store: wrap the production build with a Trusted Web Activity (TWA) or ship as a PWA. Privacy policy lives at `/privacy`.
